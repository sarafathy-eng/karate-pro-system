# 🥋 Karate Pro System

A club management system for karate academies, built as a single-file web app. It replaces paper attendance sheets and manual subscription tracking.

## ✨ Features

- ✅ **Attendance tracking** for every session
- 💳 **Subscription management**: track who has paid and who is due
- 💬 **WhatsApp integration** to contact members quickly
- 📄 **PDF export** for reports and records
